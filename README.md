# Nuevo CMD en Español

## Descripción general
Proyecto académico para construir una nueva consola en español, basada en la estructura general de la consola CMD de Windows. El enfoque principal es definir comandos en español, una experiencia coherente de línea de comandos y documentación clara del comportamiento esperado.

## Objetivo
- Diseñar y documentar una consola con comandos nativos en español, consistente y extensible.
- Establecer una arquitectura básica (bucle de lectura-evaluación-impresión, análisis y ejecución de comandos) orientada a enseñanza y experimentación.
- Proveer un mapeo sistemático entre comandos clásicos de CMD y sus equivalentes en español, con alias unificados.

## Tecnologías propuestas
- Lenguaje de implementación: por definir (se evaluarán opciones como Python 3 o Java 17).
- Pruebas: marco de pruebas nativo del lenguaje seleccionado.
- Calidad: linters y formateadores del ecosistema elegido.

Nota: Esta fase entrega únicamente documentación; no se incluye implementación de código.

## Estado inicial del proyecto
- Estado: En planificación y definición de alcance.
- Entregables actuales: documentación base del proyecto (README y documentos en `docs/`).
- Próximos pasos sugeridos: definir estructura general del sistema, tabla de comandos en español y base para lexer, parser e intérprete.
